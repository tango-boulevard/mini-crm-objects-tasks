# Мини CRM Объекты и задачи

Проект тестового задания: защищённая CRM для управления строительными объектами и задачами исполнителей.

Проект находится на этапе проектирования. Инструкции запуска, применения миграций, создания тестовых пользователей и деплоя будут добавляться вместе с реализацией, чтобы README описывал только реально работающие команды.

## Локальный запуск frontend

Требование: Node.js 20 или новее. npm устанавливается вместе с Node.js.

```bash
npm install
copy .env.example .env
npm run dev
```

Перед запуском замените значения в `.env` на URL и публичный anon key своего Supabase-проекта. Привилегированный `service_role` для frontend не нужен и не должен находиться в `.env`.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Все проверки можно запустить последовательно командой `npm run check`.

В Windows тот же набор можно запустить из корня проекта отдельным скриптом:

```powershell
.\scripts\verify.ps1
```

Скрипт останавливается на первой ошибке и возвращает ненулевой код завершения.
