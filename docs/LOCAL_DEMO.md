# Локальная демонстрация

## Подготовка

Запустите Docker Desktop, затем из корня проекта:

```powershell
npx supabase start
npx supabase db reset
npx supabase status
```

Из вывода `supabase status` скопируйте Project URL и Publishable key в `.env.local`:

```text
VITE_SUPABASE_URL=http://127.0.0.1:54321
VITE_SUPABASE_ANON_KEY=LOCAL_PUBLISHABLE_KEY
```

Не используйте строку `Secret` или `service_role` во frontend.

После этого запустите приложение:

```powershell
npm run dev
```

Приложение откроется по адресу `http://127.0.0.1:5177`.

## Локальные аккаунты

| Роль | Email | Пароль |
|---|---|---|
| Постановщик | `manager@local.test` | `Manager123!` |
| Исполнитель 1 | `executor.one@local.test` | `Executor123!` |
| Исполнитель 2 | `executor.two@local.test` | `Executor123!` |

Эти пароли существуют только в локальном seed и не предназначены для облачного окружения.

## Основной сценарий

1. Войти постановщиком и открыть объект.
2. Создать задачу для первого исполнителя.
3. Выйти и войти первым исполнителем.
4. Убедиться, что задачи второго исполнителя не видны.
5. Взять задачу в работу и отправить на проверку.
6. Войти постановщиком и вернуть задачу без комментария: интерфейс не должен позволить подтверждение.
7. Добавить комментарий и вернуть задачу на доработку.
8. Войти исполнителем, снова взять задачу в работу и отправить на проверку.
9. Войти постановщиком и принять задачу.
10. Проверить полную историю с пользователями, временем и комментарием.
