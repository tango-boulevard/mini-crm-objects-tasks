# Сообщение для сдачи тестового задания

Здравствуйте. Закончил тестовое задание «Объекты и задачи».

Работающее приложение: https://mini-crm-objects-tasks-nu.vercel.app

Тестовые доступы:

- постановщик: `manager@local.test` / `Manager123!`;
- исполнитель 1: `executor.one@local.test` / `Executor123!`;
- исполнитель 2: `executor.two@local.test` / `Executor123!`.

Репозиторий: https://github.com/tango-boulevard/mini-crm-objects-tasks

Пояснение функциональности для руководителя: `docs/FUNCTIONAL_OVERVIEW.md`

Коротко о решении. Руководитель создаёт строительные объекты и задачи, назначает исполнителей и принимает результат либо возвращает его на доработку. Исполнитель видит только назначенные ему задачи и связанные с ними объекты. Каждая смена статуса записывается в историю с автором и временем.

Ограничения доступа действуют не только в интерфейсе, но и в самой базе данных. Поэтому исполнитель не сможет получить чужую задачу прямым запросом, изменить чужие данные или самостоятельно принять выполненную работу. Разрешённость каждой смены статуса также проверяет база. Историю нельзя отредактировать или удалить через пользовательский API.

Решения и допущения описаны в `docs/DECISIONS.md`. Основные: рабочую задачу нельзя физически удалить; объект с задачами не удаляется; переназначение и редактирование разрешены только до начала работы; принятая задача считается завершённой. Пояснение функциональности для руководителя вынесено в `docs/FUNCTIONAL_OVERVIEW.md`. Не успел добавить автоматические браузерные E2E-тесты, но основной сценарий вручную проверен обеими ролями, а правила доступа и статусы покрыты 15 тестами базы данных.
